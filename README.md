# The Halloween Commit: Horror at the Server Room 🎃

## Presentació i Entorn
Aquest repositori conté l'auditoria forense i el procés d'exorcisme digital realitzat la nit del 31 d'octubre a la sala de servidors. * **Sistema Operatiu utilitzat:** Arch Linux / Cachy OS

* **Versió de Git:** Git v2.43.0
